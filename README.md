# Voxora: Speak & Learn

## Overview
Voxora is an AI-powered language learning platform designed to help users improve speaking, pronunciation, vocabulary, and conversational skills.

## Features
- AI Tutor
- Speaking Practice
- Pronunciation Scoring
- Vocabulary Builder
- Progress Tracking
- Daily Streaks
- XP and Gamification
- Personalized Learning Paths

## Tech Stack
- Built using Lovable AI
- Frontend: React (generated by Lovable)
- Backend: Supabase
- Authentication
- Database Integration

## Project Status
Prototype completed and deployed using Lovable AI.
